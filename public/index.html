Yang perlu kamu tahu

Apakah ini aplikasi resmi WhatsApp?

Tidak. STATUSX memakai Baileys sebagai integrasi WhatsApp Web tidak resmi dan tidak berafiliasi dengan Meta. API resmi tidak menyediakan endpoint untuk membaca status kontak. Jika tidak ingin memakai integrasi tidak resmi, gunakan impor lokal atau set BAILEYS_ENABLED=false.

Kenapa status tertentu tidak muncul?

Tidak ada akses ke semua status hanya dengan nomor telepon. STATUSX hanya memproses event status baru yang benar-benar diterima akun terhubung saat koleksi otomatis aktif. Status yang kedaluwarsa, tidak dibagikan kepadamu, view-once, status teks, dan history chat tidak dikoleksi.

Apakah pesan pribadi dibaca atau disimpan?

Aplikasi tidak membuat endpoint pembaca chat, tidak menyimpan percakapan pribadi, dan hanya memproses media dari status@broadcast. Protokol Baileys tetap menangani lalu lintas akun yang diperlukan untuk koneksi. Gunakan hanya akun sendiri/berizin.

Pairing atau QR gagal?

Periksa internet server, versi WhatsApp, dan Perangkat tertaut. Kode/QR selalu berasal dari Baileys, tidak dibuat sebagai demo. Autentikasi memiliki batas waktu. Coba QR jika pairing gagal. Setelah memutuskan, periksa dan cabut juga perangkat di aplikasi WhatsApp.

Apakah data permanen di Railway?

Hanya jika Railway Volume dipasang dengan benar ke direktori DATA_DIR. Mount /app/data, set DATA_DIR=/app/data, dan gunakan satu replica. Volume bukan backup; buat backup terenkripsi secara terpisah. Lihat README untuk deployment lengkap.

Bagaimana file dan sesi dilindungi?

Versi ini tidak memiliki autentikasi website: siapa pun yang dapat menjangkau URL dapat memakai galeri dan kontrol WhatsApp. Cookie otomatis hanya dipakai untuk CSRF, bukan untuk membatasi akses. Rate limiting, validasi file, dan perlindungan path tetap aktif. File sesi WhatsApp tidak disediakan lewat endpoint file. Batasi akses jaringan jika memerlukan privasi; URL rahasia saja bukan perlindungan akses. Jangan bagikan folder data.

Format dan batas file apa yang didukung?

JPG, PNG, WebP, GIF, MP4, dan WebM. Maksimal 10 file per impor. Batas per file, paket ZIP, dan kapasitas workspace mengikuti environment server. Browser mungkin tidak mendukung semua codec MP4/WebM; file tetap dapat diunduh.

Bagaimana menghentikan koneksi WhatsApp?

Tidak ada login/logout website dalam versi ini. Menutup tab tidak memutus WhatsApp. Gunakan tombol Putuskan & hapus sesi pada halaman koneksi, lalu periksa juga Perangkat tertaut di ponsel.
